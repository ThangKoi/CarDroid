# CarDroid roadmap

CarDroid is an Android launcher and receiver-sharing project in active development.

## Launcher experience

- Refine the side-by-side app layout, app switching, and customizable widget grid.
- Improve search, keyboard access, and touch behavior across supported apps.
- Keep navigation and session recovery predictable.

## Reliability

- Improve display cleanup, phone locking and unlocking, and session reconnection.
- Validate media playback, input routing, and performance across Android versions.
- Expand receiver compatibility through reproducible testing.

## Setup and releases

- Simplify permissions, helper setup, and connection guidance.
- Document supported configurations and known limitations.
- Prepare repeatable builds and release validation.

Priorities may change with device testing and user feedback. No release dates or universal compatibility are promised.
